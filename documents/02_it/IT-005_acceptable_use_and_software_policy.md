# Acceptable Use Policy (AUP)

## 1. General
Company devices, networks and accounts are provided for business use. Reasonable personal use (personal email, news, banking) is allowed as long as it does not affect work, security or bandwidth.

## 2. Prohibited
- Installing pirated, cracked or unlicensed software.
- Torrent clients, crypto-mining, or remote access tools (AnyDesk, TeamViewer) not provided by IT.
- Disabling or tampering with security agents (CrowdStrike Falcon, Intune, Netskope).
- Using **USB mass storage devices** — blocked by default; exceptions require Security approval.
- Auto-forwarding company email to personal accounts.
- Storing company data on personal cloud storage (personal Google Drive, Dropbox, iCloud).

## 3. Approved software catalog (Orbitra App Store highlights)
Chrome, Firefox, Slack, Zoom, Google Workspace, Microsoft Office, VS Code, IntelliJ IDEA (licensed), Docker Desktop (licensed), Postman, Figma, Notion (viewer), 1Password (company vault), Loom, Miro.

## 4. Generative AI tools
| Tool | Status | Data allowed |
|---|---|---|
| **OrbitBot** (internal) | Approved | Up to Confidential |
| **Claude (Orbitra Enterprise workspace)** | Approved | Up to Confidential; never Restricted |
| **GitHub Copilot Business** | Approved for engineers | Source code |
| Public free AI chatbots (personal accounts) | **Not permitted** for work | None — do not paste any internal data |
| AI meeting note-takers from third parties | Not permitted unless approved by Security | — |

Rules: never paste customer personal data, credentials, secrets or Restricted data into any AI tool. Review AI output before using it; you are accountable for the result.

## 5. Monitoring
Orbitra monitors company devices and networks for security purposes in line with applicable law and the Employee Privacy Notice. Content of personal communications is not inspected except during a formal investigation approved by Legal.

## 6. Violations
Violations are handled per HR-COC-001 and may result in disciplinary action.
