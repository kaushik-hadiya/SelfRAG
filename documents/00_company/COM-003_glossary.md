# Orbitra Glossary

| Term | Meaning |
|---|---|
| ARR | Annual Recurring Revenue |
| Anchor days | Tuesday, Wednesday, Thursday – the days India-office employees are expected in office (see HR-WFH-001) |
| BGV | Background verification, done by our vendor VeriTrust before joining |
| CTC | Cost to Company – total annual compensation including employer contributions |
| Comp-off | Compensatory day off for working on a weekend or holiday (India) |
| DRI | Directly Responsible Individual – the single owner of a task or decision |
| EL / PL | Earned Leave / Privileged Leave (same thing; India) |
| ELT | Executive Leadership Team |
| FnF | Full and Final settlement at exit |
| Freeze | Deployment freeze window where no production changes are allowed (see ENG-004) |
| HRBP | HR Business Partner |
| IC | Individual Contributor, or Incident Commander in incident context |
| LOP | Loss of Pay – unpaid leave days deducted from salary |
| LWD | Last Working Day |
| NPS | National Pension System (India) or Net Promoter Score (customer context) |
| OKR | Objectives and Key Results – set quarterly |
| OrbitBot | The internal AI assistant that answers policy and how-to questions |
| OrbitDesk | The single ticketing portal for IT, HR, Finance, Admin and Legal requests |
| PIP | Performance Improvement Plan |
| PR | Pull Request (engineering) or Purchase Request (procurement) – check context |
| PeopleHub | The HRMS for leave, attendance, payslips, letters and profile |
| PTO | Paid Time Off (US) |
| RCA | Root Cause Analysis |
| RSU / ESOP | Restricted Stock Units / Employee Stock Option Plan (see HR-COMP-001) |
| SEV | Severity level of a production incident (SEV1 = most severe) |
| SpendWise | Expense management tool |
| TA | Talent Acquisition (recruiting) |
| TPA | Third-Party Administrator for health insurance claims – CareBridge TPA |
| UAN | Universal Account Number for Provident Fund (India) |
| WFA | Work From Anywhere – up to 20 days per year (see HR-WFH-001) |
| YTD | Year to date |
